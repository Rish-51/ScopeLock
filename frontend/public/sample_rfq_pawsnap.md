# Project Brief: "PawSnap" - Instagram for Pets MVP

## Overview
We are looking for a skilled freelance mobile engineer to build the MVP of PawSnap, a photo-sharing mobile application dedicated exclusively to pets and pet parents.

## Key Functional Requirements
1. **User Authentication:** Users should be able to sign up and login with Apple ID and Google OAuth. We also need password reset via email.
2. **Pet Profiles:** Users can create up to 5 pet profiles with breed, age, and bio.
3. **Feed & Realtime Activity:** A vertical scrolling photo feed of followed pets with realtime like counters and instant push notifications when someone comments.
4. **Photo Filters & Camera:** Direct camera capture with custom animal stickers and photo cropping.
5. **In-App Purchases:** Pet parents should be able to buy 'Treat packs' (virtual currency) using Apple App Store In-App Purchases and Google Play Billing to reward content creators.
6. **Moderation & Flagging:** Basic image reporting for inappropriate content.

## Technical Constraints & Ambiguities
- The app should work smoothly on both iOS and Android.
- We want the app to be completely bug-free and scale infinitely without any slowdown.
- We expect to launch in the App Store within 4 weeks.

## Deliverables
- Source code in GitHub repository.
- TestFlight build for iOS and Internal Testing APK for Android.
- Basic admin dashboard for banned users.
